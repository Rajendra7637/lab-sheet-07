# Lab Sheet-07: Mini Projects on Unsupervised Learning

MCA 3rd Semester (2026-2027), COER University, Roorkee

| Project | Problem | Techniques |
|---|---|---|
| `project1_customer_segmentation/` | Group customers into segments | K-Means, Hierarchical, Gaussian Mixture, PCA |
| `project2_news_clustering/` | Group similar news articles | TF-IDF, SVD, K-Means, Hierarchical, t-SNE |

Both projects follow the same workflow: clean the data, scale, choose the number of
clusters, cluster, visualize, evaluate, compare techniques, save the model, and predict.

Install the libraries once: `pip install -r requirements.txt` (Python 3.11 or above).
Then open a project folder and follow its README.

See `EXAM_NOTES.md` for how to explain the projects in the viva.
